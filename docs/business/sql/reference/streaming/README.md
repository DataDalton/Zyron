# Streaming

27 statements and constructs.

- [ALTER ENDPOINT](alter-endpoint.md), Changes an endpoint's configuration, or takes it out of service.
- [ALTER EXTERNAL SINK](alter-external-sink.md), Changes a sink's configuration, or pauses writing to it.
- [ALTER EXTERNAL SOURCE](alter-external-source.md), Changes a source's configuration, or its read position.
- [ALTER PUBLICATION](alter-publication.md), Changes which tables a publication carries, or its options.
- [ALTER STREAMING JOB](alter-streaming-job.md), Pauses, resumes or reconfigures a streaming job.
- [CREATE CDC INGEST](create-cdc-ingest.md), Applies another system's change feed into a table.
- [CREATE CDC STREAM](create-cdc-stream.md), Sends one table's changes to a sink as they happen.
- [CREATE ENDPOINT](create-endpoint.md), Publishes a statement at an HTTP path.
- [CREATE EXTERNAL SINK](create-external-sink.md), Names a place outside the database that rows are written to.
- [CREATE EXTERNAL SOURCE](create-external-source.md), Names a place outside the database that rows are read from.
- [CREATE PIPELINE](create-pipeline.md), Names an ordered set of stages, each reading a source and writing a target.
- [CREATE PUBLICATION](create-publication.md), Names the set of tables, columns and rows a subscriber receives.
- [CREATE REPLICATION SLOT](create-replication-slot.md), Opens a durable position in the change log that a consumer reads from.
- [CREATE STREAMING ENDPOINT](create-streaming-endpoint.md), Publishes a publication's changes at an HTTP path, over a WebSocket or as server-sent events.
- [CREATE STREAMING JOB](create-streaming-job.md), Runs a query continuously, writing its result into a target as new rows arrive.
- [DROP CDC INGEST](drop-cdc-ingest.md), Stops applying another system's change feed.
- [DROP CDC STREAM](drop-cdc-stream.md), Stops sending a table's changes to a sink.
- [DROP ENDPOINT](drop-endpoint.md), Removes an endpoint.
- [DROP EXTERNAL SINK](drop-external-sink.md), Removes a named external sink.
- [DROP EXTERNAL SOURCE](drop-external-source.md), Removes a named external source.
- [DROP PIPELINE](drop-pipeline.md), Removes a pipeline.
- [DROP PUBLICATION](drop-publication.md), Removes a publication.
- [DROP REPLICATION SLOT](drop-replication-slot.md), Releases a held position in the change log.
- [DROP STREAMING JOB](drop-streaming-job.md), Stops a streaming job and forgets its position.
- [RUN PIPELINE](run-pipeline.md), Runs a pipeline's steps now, in order.
- [TAG PUBLICATION](tag-publication.md), Attaches a tag to a publication, for grouping and policy.
- [UNTAG PUBLICATION](untag-publication.md), Removes a tag from a publication.
