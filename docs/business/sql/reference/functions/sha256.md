# sha256

Returns the SHA-256 of the input. Suitable where a digest has to resist a deliberate collision, such as content addressing or signing, where the non-cryptographic hashes in this group are not.

## Syntax

```sql
sha256(bytes)
```

## Returns

BYTEA of 32 bytes. NULL when the input is NULL.

## Examples

```sql
SELECT hex_encode(sha256('abc'))
```

ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad.

## On a cluster

This runs on the member it arrives at and reaches no other. Nothing about it enters the consensus log.
