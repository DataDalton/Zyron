# sha512

Returns the SHA-512 of the input. It works on 64-bit words, so on a 64-bit machine it is usually faster than SHA-256 despite the wider output.

## Syntax

```sql
sha512(bytes)
```

## Returns

BYTEA of 64 bytes. NULL when the input is NULL.

## Examples

```sql
SELECT length(sha512('abc'))
```

64.

## On a cluster

This runs on the member it arrives at and reaches no other. Nothing about it enters the consensus log.
