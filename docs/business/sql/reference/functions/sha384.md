# sha384

Returns the SHA-384 of the input, a truncation of the SHA-512 computation rather than a widening of SHA-256. It resists length-extension, which SHA-512 does not.

## Syntax

```sql
sha384(bytes)
```

## Returns

BYTEA of 48 bytes. NULL when the input is NULL.

## Examples

```sql
SELECT length(sha384('abc'))
```

48.

## On a cluster

This runs on the member it arrives at and reaches no other. Nothing about it enters the consensus log.
