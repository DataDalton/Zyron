# Reading and Writing Rows

10 statements and constructs.

- [CALL](call.md), Runs a procedure.
- [COPY](copy.md), Moves rows between a table and a stream, in bulk.
- [DELETE](delete.md), Removes rows a predicate selects.
- [DO](do.md), Runs a body of statements once, without naming it.
- [INSERT](insert.md), Adds rows to a table, from written-out values or from a query.
- [MERGE](merge.md), Applies a source relation to a target, updating, deleting or inserting per row.
- [SELECT](select.md), Reads rows, shaping them with the clauses written after it.
- [TRUNCATE](truncate.md), Empties a table without reading its rows.
- [UPDATE](update.md), Changes rows in place.
- [VALUES](values.md), Yields written-out rows as a relation of their own.
